# ESP32 System Monitor

Беспроводной монитор системных ресурсов ПК на базе ESP32-C3 с OLED дисплеем.

## Особенности

-  Отображение температуры CPU/GPU
- 💾 Использование оперативной памяти
- 📡 Беспроводное подключение по Wi-Fi
- 🔋 Работа от аккумулятора
- 📱 Компактный размер

## Hardware

- ESP32-C3 SuperMini
- OLED SSD1306 0.96" (I2C)
- Li-Ion аккумулятор 1600mAh 3.7V
- Модуль зарядки IP5306
- Провода стандарта DuPont с перемычками

## Установка

1. Установите [PlatformIO](https://platformio.org/)
2. Клонируйте репозиторий
3. Подключитесь к Wi-Fi сети "ESP32_Monitor_Setup"
4. Введите данные вашей Wi-Fi сети
5. Запустите клиент на ПК

## Примечания
1. Для работы от аккумулятора необходим зарядный модуль, а также переходник, объединяющий контакты Gnd экран и модуля зарядки
